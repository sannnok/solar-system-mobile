# Воронка: ролики → боты → привычка

Цель — превращать просмотры коротких роликов в подписчиков, которые возвращаются каждый день, и
перекидывать их между двумя ботами. Всё ниже уже поддержано кодом: метки источников, подписки,
кросс-промо, статистика.

```
Reels / Shorts / TikTok / канал            ← n8n публикует по ролику в день (187 дней контента)
        │  CTA: «ссылка на бота в профиле» / «напиши КОДЕКС в комментах»
        ▼
t.me/<bias_bot>?start=b130_reels           ← карточка из ролика открывается сразу
        │  ценность в первую секунду: та же карточка, что в ролике
        ▼
Подписка «искажение дня» (выбор часа)      ← ежедневное касание, D1/D7-удержание
        │  квиз «угадай искажение» — вовлечение и повод вернуться
        ▼
После 5 карточек — приглашение в ЗОЖ-бот   ← один раз, с меткой from_bias
        ▼
t.me/<health_bot>?start=from_bias          ← советы по питанию/спорту/сну с «ловушкой мышления»
        │  трекер 1–3 привычек, серии дней, вечернее напоминание
        ▼
Ежедневная привычка → монетизация
```

Обратная связь тоже есть: в каждом ЗОЖ-совете ссылка «🧠 Ловушка мышления» ведёт в Кодекс
(`?start=b<n>_health`), так что аудитории перетекают в обе стороны.

## Метки источников

Параметр `start` — `b<номер>_<источник>` (открыть карточку) или просто `<источник>`.
Источник пишется в `users.source` при первом заходе и виден в `/stats` и в отчёте n8n.

| Где ссылка | Пример | Что произойдёт |
|---|---|---|
| Описание Reels | `t.me/BiasBot?start=b130_ig` | карточка №130, источник `ig` |
| YouTube Shorts | `t.me/BiasBot?start=b130_yt` | карточка №130, источник `yt` |
| TikTok | `t.me/BiasBot?start=tt` | приветствие + искажение дня, источник `tt` |
| Пост в канале (автоматически) | `?start=b130_channel` | кнопка под постом |
| Inline-шеринг в чатах | `?start=b130_inline` | кнопка под пересланной карточкой |
| Mini App | `?start=b130_webapp` | кнопка «Карточка в чат» |
| ЗОЖ-бот → Кодекс | `?start=b130_health` | ссылка «ловушка мышления» |
| Кодекс → ЗОЖ-бот | `?start=from_bias` | кросс-промо после 5 карточек |

Для блогеров и рекламы — своя метка на каждого: `?start=blogger_anna`.

## Что измерять

`/stats` в каждом боте (для `ADMIN_IDS`), `GET /api/stats` и еженедельный отчёт
`n8n/funnel-report.json`. События пишутся в таблицу `events`:

| Шаг воронки | Как посчитать |
|---|---|
| Просмотр → старт бота | новые пользователи с источником `ig`/`yt`/`tt` ÷ просмотры роликов (из кабинета площадки) |
| Старт → подписка | события `subscribe` ÷ `new_user` |
| Вовлечение | `quiz_right + quiz_wrong`, `more`, `search` на пользователя |
| Удержание | доля подписчиков без `blocked` через 1/7/30 дней (`users.created_at`, `last_seen`) |
| Перелив в ЗОЖ | `promo_health` → новые пользователи ЗОЖ-бота с источником `from_bias` |
| Привычка | `checkin` в день на пользователя с привычками |

Бенчмарков здесь сознательно нет — снимите базовую линию за первые 2–3 недели и меняйте по одному
параметру (крючок ролика, время рассылки, порог кросс-промо `PROMO_AFTER_CARDS`).

## Контент для роликов

* **Ролик дня** — `n8n/bias-reels.json`: следующее искажение без ролика → сценарий (Claude или
  шаблон) → озвучка ElevenLabs → mp4 1080×1920 → канал (и YouTube Shorts, когда подключите).
  Порядок совпадает с «искажением дня» в боте, так что ролик и рассылка говорят об одном.
* **Рубрики на будущее**: «угадай искажение» (пример → пауза → ответ — та же механика, что в квизе),
  «искажения в спорте и еде» (карточки ЗОЖ-бота — `renderTipCard`), «пары-двойники»
  (Форер vs Барнум, первичность vs недавность).
* **Крючок решает**: в первые 2 секунды — бытовая ситуация или вопрос («Почему мы досматриваем
  плохие фильмы?»), а не название искажения. Сценарий от Claude так и построен.
* Instagram и TikTok не дают публиковать ролики через API без бизнес-аккаунта и одобрения
  приложения — на старте выкладывайте mp4 из `out/videos` вручную или через планировщик площадки.
  YouTube Shorts и Telegram-канал n8n публикует сам.

## Идеи монетизации (когда будет ядро аудитории)

* Платный «марафон 30 дней без самообмана» в ЗОЖ-боте: те же привычки + разбор ловушек каждый день.
* PDF/постер «Кодекс искажений по-русски» — карточки уже рендерятся (`npm run cards`).
* Партнёрские интеграции в ЗОЖ-советах (трекеры, книги) — с пометкой «реклама».
* Подписка на закрытый канал с разборами.
